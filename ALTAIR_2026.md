# ALTAIR 8800 — 2026 64-bit Edition

The 2026 implementation is located under [`v2026/`](v2026/).

It adds a modern 64-bit software/hardware architecture while retaining the original project's
Altair 8800 emulator and front-panel concepts.

## Included

- x86-64 assembly
- C runtime
- 8080 compatibility model
- DDR5/NVMe/PCIe/USB4/10GbE architecture
- 3840×2160 4K display target
- interactive browser front panel
- S-100 bridge RTL
- PCB specifications
- BOM and memory map
- firmware boundary
- test plan
- Linux/Windows build scripts
- CMake/Make
- GitHub Actions CI

Start with `v2026/README.md`.
